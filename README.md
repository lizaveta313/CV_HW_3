# Домашняя работа №3

Подсчёт круглых торцов брёвен и труб с помощью Hough Circle Transform:
`cv2.HoughCircles` и `cv2.HOUGH_GRADIENT`. 

Установка и запуск из папки проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python solution.py
```

Архив распаковывается во временную папку, которая удаляется после обработки.
Изображения с зелёными окружностями, красными центрами и количеством находятся
в `results/`, вместе с `results.txt` и `parameters.txt`.

Параметры подобраны отдельно для каждого кадра после сравнения GaussianBlur
и medianBlur. Для первых трёх кадров выделена прямоугольная область с брёвнами.
Для `pipes-5` и `pipes-6` выполнены два прохода Хафа для разных размеров труб.
Координаты окружностей и количества объектов заранее не задаются.

Результаты приблизительные: эллиптические, перекрытые и обрезанные торцы могут
пропускаться, возможны ложные круги. Особенно заметны ошибки на `logs-4`
и `pipes-6`.
